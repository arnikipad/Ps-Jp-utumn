# 🍁 秋 — Japanese Autumn Animated Login

A beautiful Japanese autumn-themed animated login and signup UI built with HTML, CSS, and JavaScript.

## ✨ Features

- 🍁 Animated falling Momiji leaves
- 🌙 Japanese crescent moon
- ✨ Glowing stars and particles
- 🎴 Japanese Kanji decoration
- 💎 Glassmorphism login card
- 🔐 Login form
- 📝 Signup form
- 🔄 Login / Signup animation
- 👁 Show / Hide password
- 🔥 Password glow effect
- ✅ Form validation
- 🔔 Animated toast messages
- 📱 Responsive mobile design
- 🎨 Autumn gold, orange, red color palette
- ⚡ No framework required
